# Hidden · 0.3

Настольный помощник для разговора и задач с экрана на Electron. Сценарии и границы сходства с Ghost GPT описаны в [docs/ghost-reference.md](docs/ghost-reference.md).

## Запуск

Node.js 22+, npm, графическая сессия:

```sh
npm install
npm start
```

В настройках выберите Gemini, вставьте ключ без пунктуации и нажмите «Проверить Gemini», затем сохраните. Или передайте `GEMINI_API_KEY` через окружение. Ключ хранится в памяти до выхода, на диск не записывается. OpenAI поддерживает только текст; его ключ — отдельный `OPENAI_API_KEY`.

По умолчанию `gemini-3.5-flash-lite`. Реальная доступность и квоты зависят от проекта. Flash 3.8 в одном реальном тесте не ответил за 60 секунд; для старта рекомендуется проверенный Flash-Lite. Единичные замеры не гарантируют задержку.

## Работа

1. Добавьте резюме, вакансию и формат подсказок справа. Можно импортировать `.txt` или `.md`.
2. Выберите микрофон или системный звук и нажмите «Начать слушать». Для системного звука выберите источник. macOS может запросить доступ к микрофону/записи экрана/системному звуку.
3. После паузы речевая фраза отправляется Gemini на распознавание, затем модель выделяет вопрос и готовит подсказку. «Автоответ» можно выключить. «Обработать фразу» отправляет накопленную речь без ожидания паузы.
4. «Снимок окна» позволяет выбрать источник и увидеть снимок. «Подсказать» отправляет его вместе с вопросом. Изображение не попадает в локальную историю.
5. «Компактно» включает прозрачную панель шириной 620 пикселей. Фон регулируется от 15 до 85%, текст остаётся непрозрачным. Окно растёт и уменьшается по ответу; у границы рабочего стола ответ становится прокручиваемым. Перетащите панель за верхнюю строку. «Управление звуком» раскрывает выбор источника и локальную проверку.
6. «Остановить» прекращает захват, очищает очередь и отменяет запрос аудио. Полный выход прекращает захват и удаляет ключ из памяти.

«Скрыть и остановить» прекращает аудиозахват, отменяет запросы и убирает окно. Обычное «Скрыть / вернуть» оставляет аудиосессию работающей. Компактный режим включает закрепление поверх окон, при разворачивании восстанавливает прежнее закрепление. История доступна кнопками назад/вперёд, новые аудиоответы не прерывают просмотр старого.

Горячие клавиши: Cmd/Ctrl+Shift+Escape — скрыть и остановить; Cmd/Ctrl+Shift+Left/Right — предыдущий/следующий ответ; Cmd/Ctrl+Shift+H — скрыть/вернуть окно; Cmd/Ctrl+Shift+Space — ответ на последний вопрос; Cmd/Ctrl+Shift+S — снимок последнего выбранного источника; Cmd/Ctrl+Enter — отправить текст; Cmd/Ctrl+Shift+M — включить/выключить пропуск кликов через компактное окно. Скрытие и возврат также выключают пропуск кликов.

«Проверить звук» запускает только индикатор уровня: ключ не нужен, аудио не передаётся в API. На macOS сборка включает нативный модуль ScreenCaptureKit, получающий только аудио; при отказе он пробует Chromium. Для нативного модуля нужен доступ к «Запись экрана и системного звука», для Chromium — доступ к системному звуку. В проверенной конфигурации macOS текущая сборка добавлена в верхнюю категорию; её нельзя одновременно вручную добавить в нижнюю категорию «Только запись системного звука». После смены локальной подписи macOS может потребовать повторно добавить текущую сборку.

Для речи собеседника в наушниках выбирайте системный звук. Loopback может захватывать звук других приложений. Если аудиотрек отсутствует/уже завершён, приложение сообщает об этом. В режиме `npm start` macOS может приписывать разрешение приложению, из которого запущен Electron. [Ограничения Electron](https://www.electronjs.org/docs/latest/api/desktop-capturer#macos-versions-142-or-higher).

## Защита окна

`setContentProtection(true)` включён до первого показа на macOS и Windows. **Универсальная невидимость в Chrome, Zoom, Meet, Teams не обеспечена:** macOS ScreenCaptureKit может захватить защищённое окно. [Документация](https://www.electronjs.org/docs/latest/api/browser-window#winsetcontentprotectionenable-macos-windows).

Проверка флага, скрытия/возврата и пустой скриншот в одном механизме захвата не доказывают невидимость в других. Передавайте отдельное окно другого приложения и проверяйте результат у зрителя. Linux этим API не защищён. Скрытие убирает окно также с вашего экрана.

## Данные

- Ключи находятся только в основном процессе; renderer получает лишь статус наличия ключа.
- История последних 30 вопросов/ответов, пользовательский контекст, промпт и модели сохраняются в localStorage без шифрования. «Очистить» удаляет историю; поля контекста и формата очищаются отдельно.
- Расшифровка последних 40 фраз находится в памяти. В API передаются до 12 000 последних символов диалога. Уже полученные ответы также передаются, чтобы уменьшить повторные подсказки.
- Аудиофрагменты и снимки не записываются на диск приложением. Для очереди разрешено до трёх аудиофрагментов; при перегрузке сессия останавливается с сообщением.
- Запросы Gemini используют `store: false`. Это не обещание отсутствия любых журналов на стороне провайдера. [Interactions API](https://aistudio.google.com/docs/interactions-overview).

## Проверки

```sh
npm test
npm run test:smoke
npm run test:fixtures
```

Unit-тесты проверяют кодирование WAV, сегментацию речи, SSE с разрезанными UTF-8 символами, валидацию запросов/медиа, разбор ответов и ошибки API. Smoke-тест использует отдельный временный профиль, подменяет только API и включает фальшивый микрофон Chromium: проверяет настройки, разделение ключей, потоковую выдачу, изображение, компактный режим, начало/остановку аудиосессии, изоляцию renderer, флаг защиты и скрытие окна. Платные запросы не выполняет.

Для **реального API-теста**, расходующего квоту, задайте `GEMINI_API_KEY` и запустите `npm run test:live`. Нужны `artifacts/task.png` (создаётся smoke-тестом), `artifacts/question.wav` и `artifacts/statement.wav` (на macOS создаются `npm run test:fixtures` голосом Samantha). Проверяются потоковый текст, изображение, вопрос из аудио, ручной режим, тишина и речь без вопроса. Отчёт — `artifacts/api-check.json`, без ключа. `npm run test:live -- --fast` исключает сравнительный тест Flash 3.8. Проведённые проверки и ограничения описаны в [docs/validation.md](docs/validation.md).

Реальный Zoom/Meet/Teams, качество длительного разговора, разные голоса и разные ОС требуют отдельных приёмочных проверок. Пока нет постоянного Gemini Live WebSocket, диаризации, RAG и поиска по PDF/DOCX, установщика, подписи Developer ID и автообновлений.

Аудит удобства и фактический локальный тест захвата Chrome от 4 ноября 2026: [docs/usability-privacy-review.md](docs/usability-privacy-review.md).

## Сборка Hidden.app

```sh
npm run package:mac
```

Готовое приложение: `dist/Hidden-darwin-<arch>/Hidden.app`. Имя в Dock и меню macOS — Hidden. Сборка подписывается локальной ad-hoc подписью, без notarization и сертификата распространения Apple. Исходники: https://github.com/EshkirenokCode/Hidden.

Проверенная локальная установка: `~/Applications/Hidden.app`. Рекомендуется запускать приложение из локальной папки Applications, а не из синхронизируемой iCloud папки сборки.

В версии 0.4.1 демонстрационный ответ не заполняет поле вопроса. Последний распознанный вопрос подставляется автоматически, если нет собственного черновика. Кнопка «Взять распознанный» заменяет черновик явно. После успешной ручной отправки поле очищается; текст, изменённый во время запроса, сохраняется. В компактном режиме строка «Услышано» показывает последнюю расшифровку. Новая аудиосессия возвращает показ свежих ответов, а просмотр истории внутри сессии по-прежнему не прерывается.
