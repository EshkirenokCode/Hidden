# Сценарии Ghost GPT и реализация 0.2

Изучены 1 ноября 2026: публичный сайт, официальный канал и доступный экран установленного `/Applications/GhostGPT.app`. Облачная сессия оригинала и его платные возможности не запускались.

Источники: [сайт](https://ghostgpt.tech/), [канал разработчиков](https://t.me/s/ghost_gpt_ai).

В установленном виджете непосредственно наблюдались кнопки «Спросить», «Скриншот», ручной запрос, навигация между ответами. Объявления разработчиков описывают прослушивание диалога, ответы, автоопределение вопроса, пользовательский контекст, кастомные промпты и RAG. Утверждения о скорости и скрытии — заявления разработчиков, не независимый тест совместимости.

| Сценарий | В нашем приложении |
|---|---|
| Слушать собеседника | Микрофон или системный loopback, явное начало/остановка, индикатор уровня |
| Определять вопрос | Расшифровка фразы после паузы, затем выделение завершённого вопроса моделью |
| Автоматически подсказывать | Автоответ, который можно выключить; предыдущий диалог передаётся как контекст |
| Спросить вручную | Текст или последний распознанный вопрос; Cmd/Ctrl+Shift+Space |
| Решать задачу с экрана | Выбор окна/экрана, снимок, просмотр и явная отправка Gemini; Cmd/Ctrl+Shift+S повторяет снимок последнего источника |
| Удобный виджет | Компактное окно 650×650, закрепление поверх окон, скрытие Cmd/Ctrl+Shift+H |
| Контекст | Текст или импорт txt/md, формат подсказок, локальная история последних 30 ответов |
| Быстрое появление текста | SSE для ручного запроса и снимка, замер первого текста и полного ответа |
| Невидимость при трансляции | Доступная защита ОС включена до первого показа. Универсальная невидимость не обеспечена: macOS ScreenCaptureKit может захватить окно |
| RAG, PDF/DOCX резюме, аккаунты, подписки | Пока не реализовано |

Аудио обрабатывается фрагментами до 15 секунд после паузы около 850 мс. Это не постоянный WebSocket Live API: на каждую речевую фразу отправляется запрос распознавания, затем запрос определения вопроса/подсказки. Повторные вопросы и продолжения определяет модель; это может ошибаться. Локальный VAD использует порог громкости, не отдельную модель распознавания речи. Одновременное распознавание разных спикеров/диаризация не реализовано.

Системный loopback может включать звук других приложений и зависит от разрешений ОС. Микрофон не гарантирует получение голоса удалённого собеседника в наушниках. Ограничения macOS: [Electron desktopCapturer](https://www.electronjs.org/docs/latest/api/desktop-capturer#macos-versions-142-or-higher), [защита окон](https://www.electronjs.org/docs/latest/api/browser-window#winsetcontentprotectionenable-macos-windows).

Исходники, брендинг и ресурсы оригинального приложения не копировались.
