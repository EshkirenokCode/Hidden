Подключение ИИ

Текст вопроса и справочный контекст передаются выбранному провайдеру ответов. Gemini распознаёт речь. В режиме «Распознать текст» снимок обрабатывается на Mac, а Groq получает текст. В остальных режимах выбранная модель получает снимок.

Live передаёт звук во время слушания и показывает текст по мере речи. Нужен доступ к модели Transcribe Live и её квота. Режим применяется при следующем запуске.

Ключ сохраняется в зашифрованном виде на этом устройстве. Пустое поле сохраняет текущий ключ.

Горячие клавиши

Нажмите на поле, затем нужное сочетание с Cmd/Ctrl или Alt. Изменения применяются кнопкой «Сохранить».

Выберите окно или экран

Для снимка будет захвачено только выбранное окно. Для системного звука используется loopback устройства; он может включать звук других приложений.
